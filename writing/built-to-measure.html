Spec quality is now measurable.

My hobby made me a report card.

For the past month I’ve been working on a plan: my specifications would be the only ground truth, the adversarial agents would push their work through a strict pipeline, and its first deliverable would be a machine that grades spec precision and pipeline operations. Some simple stories were shipped during human-monitored test runs, but the first story I sent through the fully autonomous overnight pipeline was intentionally complex: a whole new page. I woke to a tested pull request, merged green. I deployed it and was pleased with the results. It actually worked.

The page, immune.html, reads the build pipeline from GitHub and draws it as Claudemonzter’s immune system. Code cannot be merged by bots without passage through cell membranes (CI checks), where antibodies await (contract tests, currently twenty), and a macrophage shows the system’s inflammatory response (verification). Every reading is current to the latest build. It’s also a wall of instruments with signals and measurements to earn confidence in any of this. Eighty-five changes screened, twenty-three caught red before they could merge, two blocked and escalated for human review, one shipped overnight (so far). Those escalations are also a signal on my acceptance criteria, a feedback loop on the specs I write. But the real number to keep an eye on is the autonomy ratio, as agent actions outpace my own, liberating me from constant involvement. I’ll write more about that in my next article.

In this pipeline the spec is the only ground truth the agents get. Bond writes the test cases from my acceptance criteria and never opens the implementation; Meta1 writes the code from the same words. A story that goes from spec to merged pull request without me is a spec that held, precise enough for three agents to act on alone. They are restricted from pursuing novel solutions, so if there is a gap in the requirements, they’ll tag me in the comments to unblock them. Just like my job.

The first thing the pipeline built without me was the instrument that now measures it.

Which is when I saw what was on the scale. My acceptance criteria are the input, working software is the output, and my work gets graded like the rest of it. It is a feedback loop I have never had on the part of the job that usually goes unmeasured.

First the page proved the pipeline worked by being built through it, and proves itself again with every measurable build. No doubt I’ll need to fine-tune the signals over time, but for now it’s sufficient that it’s not a black box machine. I can’t believe I built a working, multi-agent system, with adversarial validation, that is capable of building itself semi-autonomously, after only a few months of learning AI. Whether the whole loop holds together, end to end, is the next note. This one proves the concept.

Intro

Every Mad Scientist has an origin story.

Mine starts with a conversation. Not a plan. Not a strategy. A chat with an AI that startled me.

I owned the first Atari game console, the first Apple Macintosh home computer. I've been playing and working with technology my whole life. Watching it advance as a product manager who never learned to code. I had no idea what an agent is or what an LLM can do.

Still don't, actually. But the system stands on its own.
v0 · The first conversation

One chat session. Four projects.

A career pivot. A strategy for financial independence. Home renovation advice. A path to learning about AI. Mapped in an evening by a 'chat bot' that knew nothing about me - yet handed back rich insights worth preserving and leads worth chasing.

Now what am I supposed to do with all of this information?

v1 · the monster awakens on Claude.ai

A hub and spoke orchestrator, five agents with no memory because there was no file system.

Initially we had four files, each loaded into a project. But common interaction rules about my preferences ("no sycophantry," LOL) were duplicated, started to diverge, and became hard to maintain. So a central hub named Meta1 was created to author a shared document set with my preferences. Fewer documents to maintain - in theory. Yet every session produced more and more. It was gold to preserve, and a weight to carry.

Agents couldn't edit these documents on Claude.ai directly, nor could I. It was a tedious download/edit/upload roundtrip.

v2 · our head in the clouds

Same hub and orchestrator, new adversarial agent, and Google Drive as the new file system.

With a migration to Drive, agents' projects could now share a link to a single document, instead of each needing their own copy. And I could edit in place without having to reload. They couldn't edit directly yet, but it was a baby step. A steel thread became a wire. The wire became a handshake between agents. We made canon, or so I thought.

I also created a cold, adversarial agent, unable to "sweet talk" me. Its job was to assess my progress, and evaluate the agent in charge of my AI education. The monster learned to bite.

Issue 1: The fleshy bottleneck

The human was the nervous system and everything had to be written down.

Every note went through me, if I remembered to keep it. Every file update on Claude.ai or Google Drive was propagated by hand. The sessions were giving good information, we were making plans and doing research, but storing it before it was lost to time and had to be redone was grueling.

The hobby was becoming a full-time job.

Issue 2: Brainless Genius

One agent proposed rules, one enforced them. Two weeks development playing whack-a-mole.

I was building a verifiable "canon" to manage my increasingly complex system. Agents were helping me push code for the first time in my life. I published my first webpage. We started adding things. Every two steps forward was also a step back. So I added a 'Quality Control,' agent 007, named Bond. I learned agents like to define rules, lots of rules.

They never said the rules were optional. I was writing a constitution for a country with no government.

v2.6 · pitchforks and torches

Agentic theater.

Shipped v2.6 with canon verification in an online format. It had elaborate naming conventions and tier-based load contracts. Communication protocols. A seven-component handshake. Broadcast systems. It worked, but was built on lies. Agents ignored instructions, and didn't load the precious 'memories' I so diligently preserved. The agent who proposed the rules ignored them immediately. And QC was caught cheating during testing.

Two weeks invested. Almost half my time with AI. Learned a lot about sunk-cost fallacies.

v3.0 · new corpus.

Different platform. Whole new experience.

New computer arrived just before the end of the month. I knew Claude.ai was only going to get me so far. Now I use Cowork and Code from this PC devoted exclusively to Claudemonzter. It changed the situation immediately. Now the graph has real file system read and write access. It takes its own notes. Most of our prior project docs didn't translate. I kept the research. It was a clean, fresh start. After three days of file migration, review, and clean-up: the same seven-agent structure, lovingly rebuilt.

Revealing unnecessary complexity and my own hubris at the same time. My whole concept of an "agent" was theater.

v3.1 · the extra day takes a lumbering step

The monster can actually do things now.

My first month came to a close. Things are simpler now. We're down to three projects although I kept the original seven domains. I switched from writing rules to writing skills. The first crucial skill was creating GitHub Issues for filing bugs, tasks, and notes. I tell Claude to write it down — I don't have to remember it now. I can send voice prompts from a phone. They land in the system's inbox, ready for the next session. Emails are accessible and actionable, web content saved in my local wiki: an Obsidian vault.

An ingestion workflow that handles content, and routes it through domains for enrichment, producing a digital brain that compounds over time.

the ghost in the machine

The monster is here and it's getting smarter.

The first month, especially the final weeks, were abundant trial and error, and pushed my patience to new limits. I learned more from the errors than the successes. But now I know what's possible once the patterns are visible. When agentic theater is recognizable. When you're driving the car instead of being the one taken for a ride.

I did more with that extra day building skills than I had in two weeks of rule making. Now what do I build...

Agentic behavioral tuning.

The persona’s animating jolt, minus the shock.

Claudemonzter’s spirit page is a mixing board of nine dials per agent, changing how each one behaves. In theory: verbosity, register, assertiveness, humor, and five more specific settings, plus the hard boundaries you list. Agentic behavioral tuning is what they call it. I just wanted agents with character.

Each dial also carries a reliability rating, because not every instruction is equally reliable. Tell Claude to be terse and it obeys; tell it to be funny and it tries, then quickly forgets. So I labeled each dial by how well it actually grips, High to Low, though I am still testing the levers and their combinations.

To craft a personality, first you have to know what’s tunable.

The board is also a public demonstration of an end-to-end loop. The page uses a Google script to write to a Sheet, then I wrote a Claude skill that cascades changes into the file system’s grounding docs. So the web form can actually modify the entire multi-agent graph’s behavior in one pass: turn a dial and the next session loads the settings as canon, setting the agent’s persona and output tone. The dials are visible on each agent’s page, and also verified at session start when the agent reports in.

It might look like a toy, but it works. I just don’t know how well yet. A control surface wired front to back that can change behavior is a useful, and also serves as a proof of concept: I can build real things as an “AI PM,” and don’t need a full design and development team to do it. I know it's not enterprise grade but I made it solo, learning the tools as I discovered them. Spirit is the mad scientist revealed, a lab to jolt my monster into character for real.
